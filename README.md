# landon2199.github.io

Source of my GIS portfolio site, served by GitHub Pages at **https://landon2199.github.io**.

Plain HTML and CSS, no build step: edit `index.html` (projects, skills, certifications, experience), commit, and Pages republishes from `main`.

| Path | What it is |
|---|---|
| `index.html` | Home page: projects, research, skills, certifications and training, experience, contact |
| `assets/css/site.css` | Styles, light and dark themes |
| `assets/img/` | Project thumbnails (each copied from its project's repository) |

Project repositories: [sentinel2-landcover-ml](https://github.com/landon2199/sentinel2-landcover-ml) · [open-earth-mcp](https://github.com/landon2199/open-earth-mcp) · [houston-heat-hotspots](https://github.com/landon2199/houston-heat-hotspots) · [arcgis-accuracy-toolbox](https://github.com/landon2199/arcgis-accuracy-toolbox) · [geoai-embedding-search](https://github.com/landon2199/geoai-embedding-search) · [texas-covid-spacetime](https://github.com/landon2199/texas-covid-spacetime) · [geoai-sam-naip](https://github.com/landon2199/geoai-sam-naip) · [brazos-fire-access](https://github.com/landon2199/brazos-fire-access) · [texas-flood-exposure-sql](https://github.com/landon2199/texas-flood-exposure-sql) · [college-station-daylight](https://github.com/landon2199/college-station-daylight)
